# Order Tracker Owner Guide

1. **How to Log In:** Open the app link, type email `demo@distributor.pk` and password `password123`, then click **Sign In**.
2. **How to Add a New Order:** Tap **New Order** at the bottom. Search and select a customer (or click **Add Inline** to type a new shop name and phone), add items and quantities, and tap **Log Order**.
3. **How to Search & Filter Orders:** Tap **Orders** at the bottom. Use the search bar to find customer shops/phones, or click the tabs (Pending, Confirmed, Delivered, Paid) to see status counts.
4. **How to Change Order Status:** Tap any order row on the Orders board to expand it, then tap one of the status buttons (e.g., Confirmed, Paid) to update it instantly.
5. **How to Share to WhatsApp:** Tap any order row to expand it, then click **Share to WhatsApp** to open a chat with that customer with the pre-filled order receipt.
